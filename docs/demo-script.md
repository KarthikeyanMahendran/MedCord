# Rural Case Rooms: 3-minute demo script

Use test data only. Log in with the demo accounts in `dev-accounts.md`.

1. **Problem (20 s).** A village health worker meets a patient and the nearest doctor is hours away.
2. **ASHA sends a case (40 s).** Sign in as the health worker. Tap "Chest pain", speak a short complaint, add SpO2 88. Send.
3. **Instant triage (30 s).** Show the RED badge, the red-flag advice, and the SBAR summary. Mention that similar answered cases appear straight away.
4. **Doctor answers (40 s).** Sign in as a doctor in a second window. Accept the case from the queue, chat in the case room, post the verified answer.
5. **Library and follow-up (20 s).** Show the answer in the Verified Answer Library. Mention the 24-hour follow-up that reopens the case as RED if the patient is worse.
6. **Escalation and impact (20 s).** Explain the timer: unanswered RED cases notify other doctors after 5 minutes, then admins. Open the Impact page.
7. **Nexconn (10 s).** Real-time case messages and calls run on the Nexconn Chat SDK.

Backup: record this run as a video in case the network fails on the day.
